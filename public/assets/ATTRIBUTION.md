# TAPEOUT visual assets

The current build uses procedural geometry, generated canvas textures, shaders,
and Web Audio. No third-party visual or audio asset is currently shipped.

Future authored assets must record:

- asset filename and in-game use
- creator and source URL
- license and attribution text
- local modifications
- triangle count, texture dimensions, and compressed size

Only original, commissioned, CC0, or explicitly compatible assets may be added.
Audio remains synthesized unless that project constraint is changed separately.
